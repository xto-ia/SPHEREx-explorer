# images/

Static photographs and artwork used by the site (mission imagery, reference
shots, documentation figures).

Files placed here are served as-is at `/images/<file>` — for example
`frontend/public/images/launch.jpg` is reachable from
`<img src="/images/launch.jpg" />`.

Keep the originals reasonably compressed (WebP or JPEG, ideally < 400 KB) so
the site stays fast on the free static host.
